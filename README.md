## 快速开始

### 安装

```
1. 下载仓库最新 Release 中的插件压缩包
2. AstrBot WebUI → 插件管理 → 上传插件包
3. 启用插件
4. 群内发送 /复读开启
```

### 依赖

| 依赖 | 版本 | 用途 |
|------|------|------|
| AstrBot | `>=4.0.0` | 运行平台 |
| Playwright | 任意 | 关系图截图（可选，缺失则无法生成关系图） |

```bash
pip install playwright
playwright install chromium
```

## 配置详解

插件提供 **10 组 45 项**配置，在 AstrBot WebUI 管理面板中直接调整。以下是完整说明。

### 🎯 复读判定（7 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 触发阈值 | int | 3 | 窗口中多少条相似消息触发复读，越小越灵敏 |
| 窗口大小 | int | 5 | 回顾最近 N 条消息，越大越宽松 |
| 模糊匹配灵敏度 | float | 0.9 | 1.0=完全一致，0.9=允许 10% 差异 |
| 权重衰减 | bool | 关 | 开启后新消息权重更高 |
| 同用户连续刷 | bool | 开 | 关=必须是不同人发相同内容才触发 |
| 最小消息长度 | int | 0 | 低于此长度不参与复读；0 表示不限制 |
| 最大消息长度 | int | 200 | 超过此长度不参与复读，防长文转发刷屏 |

### ⏱️ 冷却与抑制（4 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 复读冷却 | int | 10s | 同一群两次复读最小间隔 |
| 冷却递增 | bool | 开 | 连续触发时冷却逐次递增（最多 6 倍），5 分钟无触发回落 |
| 重复抑制 | int | 60s | 同一条消息 N 秒内只复读一次 |
| 打断惩罚倍率 | float | 2.0 | 打断对群聊干扰更大，额外延长冷却 |

### 🎭 打断系统（6 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 打断基础概率 | float | 0.1 | 触发复读时进入打断分支的概率，随重复次数递增 |
| 原话洗牌 | bool | 开 | 将消息文字随机打乱后发出 |
| 反向复读 | bool | 开 | 将消息文字反转输出 |
| 自定义话术 | bool | 关 | 从自定义话术列表中随机抽取一句发送 |
| 终止复读 | bool | 关 | 不发送任何消息，仅施加冷却惩罚 |
| 自定义打断话术 | text | 见默认 | 每行一句，启用自定义话术时随机抽取 |

### 🎨 复读风格（2 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 模拟延迟 | string | 0.5-2.0s | 复读前随机等待范围，让机器人更像真人 |
| 极速模式 | bool | 开 | 跳过所有延迟，立即回复 |

### 🛡️ 过滤（3 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 内容黑名单 | regex | `admin\|【\|抽老婆\|抽老公` | 匹配此正则的消息跳过复读 |
| 屏蔽群号 | text | 空 | 逗号或换行分隔，也可用 `/复读关闭` 临时关闭 |
| 屏蔽用户 QQ | text | 空 | 这些用户的消息不触发复读 |

### 💕 抽取设置（10 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 开启老公模式 | bool | 开 | `/今日老公` `/抽老公` `/强娶老公` 生效 |
| 开启老婆模式 | bool | 开 | `/今日老婆` `/抽老婆` `/强娶老婆` 生效 |
| 每人每群每日随机抽取次数 | int | 10 | 每群独立计数；强娶/求婚不会占用、返还或重置 |
| 活跃天数 | int | 30 | 最近 N 天发过言的人进入随机抽取池；不影响强娶 |
| 随机抽取仅限活跃成员 | bool | 关 | 关=随机抽取改用全群成员；强娶始终不受此项限制 |
| 概率衰减天数 | int | 7 | 被抽中的人概率降低，N 天后完全恢复。1=几乎无衰减，30=极分散 |
| 排除用户 QQ | text | 空 | 这些 QQ 号不参与随机抽取、强娶和求婚 |
| 活跃候选池人数上限 | int | 500 | 仅活跃模式下，候选人数超过此值时随机截取 |
| 群组白名单 | text | 空 | 仅这些群启用抽人功能 |
| 群组黑名单 | text | 空 | 这些群禁用抽人功能 |

### 💍 强娶与求婚（5 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 强娶冷却天数 | int | 3 | 使用 `/强娶` 后需等待的天数 |
| 每人每群每日强娶次数 | int | 3 | 每个群分别计数，0=不限制 |
| 每人每日求婚次数 | int | 3 | 所有群共享；拒绝或超时自动返还，0=不限制 |
| 求婚冷却 | int | 86400s | 所有群共享；拒绝或超时自动返还，默认 1 天 |
| 允许与机器人建立关系 | bool | 关 | 开启后允许强娶或向机器人求婚 |

### ⚙️ 高级选项（6 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 关键词触发 | bool | 开 | 免 `/` 前缀，直接发"抽老公"即可触发 |
| 关键词匹配模式 | string | exact | exact=完全匹配，starts_with=前缀，contains=包含 |
| @ 中奖人 | bool | 关 | 抽取结果中自动 @ 被抽到的用户 |
| 双向绑定 | bool | 关 | A 抽到 B 时自动给 B 也分配 A |
| 自动撤回 | bool | 关 | 抽取结果在指定秒数后自动撤回 |
| 撤回延迟 | int | 30s | 自动撤回前等待的秒数 |


### 🖼️ 关系图（1 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 关系图布局计算次数 | int | 100 | 节点越多可适当提高；数值越高生成越慢 |

## 关系图技术说明

### 渲染引擎

采用 **Vis.js 力导向布局** + **Playwright 截图**，完全替代旧的 PIL 绘图方案：

| 参数 | 说明 |
|------|------|
| 布局引擎 | Vis.js Barnes-Hut 力导向，CDN 加载（jsdelivr + unpkg 回退），迭代 100 轮 |
| 输出格式 | Playwright 截图 PNG，1600×900 |
| 主题 | 深色背景 + 节点发光 + 贝塞尔曲线边 |
| 边类型 | 4 色区分：抽取（青）、强娶（橙）、双向（黄）、求婚（粉） |
| 双向边 | curvedCCW 反向弯曲，避免重叠 |
| 节点角色 | 蓝色边框=抽取者，红色=被抽者，紫色=双向 |

### 性能优化

- `asyncio.gather` 并行获取群名 + 成员列表，大群减少 1-3 秒
- 渲染失败自动重试（最多 2 次），避免偶发 Playwright 超时报错
- 先发送"正在生成"提示，避免用户干等

## 常见问题

<details>
<summary><b>Q: 关系图生成失败？</b></summary>

常见原因：Playwright 未安装或 chromium 未下载。运行 `pip install playwright && playwright install chromium`。v2.0.3 起已加入自动重试机制，偶发失败会自动重试。
</details>

<details>
<summary><b>Q: 如何同时开启老公和老婆模式？</b></summary>

管理面板中同时勾选「开启老公模式」和「开启老婆模式」即可。两个模式共享数据池，仅话术和指令前缀不同。用户可用 `/今日老公` 和 `/今日老婆` 分别抽取。
</details>

<details>
<summary><b>Q: 复读太频繁 / 太少怎么办？</b></summary>

调整「触发阈值」（默认 3）和「窗口大小」（默认 5）。阈值越低、窗口越大，越容易触发。冷却时间（默认 10s）和冷却递增也会影响频率。
</details>

<details>
<summary><b>Q: 如何让复读更自然？</b></summary>

- 开启「模拟延迟」（默认 0.5-2.0s），机器人不会秒回
- 关闭「极速模式」
- 关闭「同用户连续刷」，只有不同人发相同内容才触发
- 开启「权重衰减」，新消息权重更高
</details>

<details>
<summary><b>Q: 数据会丢失吗？</b></summary>

v2.1.5 起，抽取记录、独立的每日抽取额度、活跃数据及强娶/求婚状态统一保存到 AstrBot 的 `data/plugin_data/astrbot_plugin_repeat_promax/`，后续更新或重装不会再随插件目录一起删除。

从 v2.1.4 及更早版本首次升级时，请先备份旧插件目录中的 `data/`。如果采用原目录覆盖安装，插件首次启动会自动迁移；如果 AstrBot 采用“先删旧目录再更新”的方式，请先把旧数据复制到上述标准持久化目录。
</details>

<details>
<summary><b>Q: 感觉总是抽到同几个人？</b></summary>

v2.0.5 起引入概率衰减加权：被抽中的人概率会降低（最低降至 1/20），随时间自然恢复（默认 7 天完全恢复）。在后台「抽取设置 → 概率衰减天数」中可调整，设为 1 则几乎无衰减。
</details>

<details>
<summary><b>Q: 如何排除某个群或某个用户？</b></summary>

- 群：在管理面板「屏蔽群号」中填写，或在群内发送 `/复读关闭`
- 用户：在管理面板「屏蔽用户 QQ」中填写
